Connect to AI

Connect Claude, ChatGPT or Claude Code to lawkitty so your assistant cites real sources instead of guessing.

1. Generate a token

Sign in, then go to Account → MCP connector → Generate token. It shows ready-to-copy snippets for each app below.

Claude Desktop

Settings → Developer → Edit Config, then add this to claude_desktop_config.json:

claude_desktop_config.json
{
  "mcpServers": {
    "lawkitty": {
      "type": "http",
      "url": "https://lawkitty.app/mcp/YOUR_TOKEN"
    }
  }
}

Or use the GUI: Settings → Developer → Add Custom Connector, name it lawkitty and paste the URL https://lawkitty.app/mcp/YOUR_TOKEN. Restart Claude Desktop to pick it up.

Leave the OAuth fields blank. lawkitty authenticates through the token in the URL, so there is no API key or OAuth flow to fill in. If Claude Desktop asks for a client ID, secret, or authorization URL, leave them empty.

ChatGPT

Settings → Apps & Connectors → Add connector, then paste your connector URL. Leave any OAuth or API key fields blank. The token in the URL is all the authentication you need.

connector URL
https://lawkitty.app/mcp/YOUR_TOKEN

Claude Code

Run this in your terminal:

terminal
claude mcp add --transport http lawkitty https://lawkitty.app/mcp/YOUR_TOKEN
