Connect to AI

Connect Claude, ChatGPT or Claude Code to lawkitty so your assistant cites real sources instead of guessing.

Connect with a link

Add lawkitty to your AI app with this link. The app then opens lawkitty to sign you in with Google, Microsoft or a login code, and asks you to Allow access. There is no token to copy or keep safe, and your assistant sees exactly the sources your account can open.

connector link
https://lawkitty.app/mcp

Claude (web and desktop)

Settings → Connectors → Add custom connector. Name it lawkitty, paste the link, then click Connect and sign in. Leave the advanced OAuth fields empty: lawkitty registers Claude for you.

ChatGPT

Settings → Apps & Connectors → Create, paste the link and choose OAuth authentication, then sign in when ChatGPT opens lawkitty.

Claude Code

Run this in your terminal, then run /mcp inside Claude Code and choose lawkitty to sign in:

terminal
claude mcp add --transport http lawkitty https://lawkitty.app/mcp

Advanced: connect with a token

For clients that cannot open a browser to sign in. Sign in, go to Account → MCP connector → Generate token, and use https://lawkitty.app/mcp/YOUR_TOKEN as the URL. Anyone holding the token can use your access, so keep it private and revoke it from the same page when you no longer need it.
